One-time fix: Poomala ↔ Thodupuzha timings

This page runs once, in your browser, and writes the correct timetable, stop offsets and coordinates into Firestore. You can delete this file afterwards — it is not part of the real site.

Step 1 — paste your Firebase config

Open js/firebase-config.js in a text editor, copy the object inside window.FIREBASE_CONFIG = { ... }, and paste just that { ... } part below.

Waiting...

If you see a permission error: open Firebase Console → Firestore Database → Rules, and temporarily allow writes to routes/poomala-thodupuzha for a signed-in or test user, run this page once, then put your rules back.
